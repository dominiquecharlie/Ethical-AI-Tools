# Volunteer scheduling tool: Workflow

Date: November 9, 2026

## Steps that run the same way every time

Build the weekly schedule
1. Read the week's sign-up sheet, with names removed except first names.
2. Write one row for each shift in the schedule table.
3. Mark any shift with no volunteer as open.

Send reminders
1. Find every shift that starts in two days.
2. Write one reminder for each volunteer, using the same message layout.
3. Show the coordinator the reminders before anything is sent.

## What the AI researches

Which open shifts are hardest to fill, based on the last eight weeks of the schedule.

## Where it looks

Our own schedule table and the sign-up sheets saved in the program folder.
