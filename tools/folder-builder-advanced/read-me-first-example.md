# Maple Street Neighbors: Read me first

Date: November 9, 2026 | Review date: February 9, 2027

## What this folder is

This folder holds what an AI tool needs to know about Maple Street Neighbors and the volunteer scheduling tool we build. Read the files in the order below before you answer.

## Read these files, in this order

| Order | File | Use it when | Loads |
|---|---|---|---|
| 1 | about-us.md | Always. | Every time |
| 2 | values.md | Always. | Every time |
| 3 | data-rules.md | Before you use anything we paste in. | Every time |
| 4 | voice-profile.md | You write for us. | Writing tasks |
| 5 | use-cases.md | You decide whether a task belongs in the tool. | Planning tasks |
| 6 | tool-list.md | We ask about vendors or models. | Planning tasks |

## Program folders

| Program | Folder | Use it when |
|---|---|---|
| Volunteer scheduling tool | volunteer-scheduling/ | The task is about shifts, volunteers or reminders. |
| Neighbor newsletter | newsletter/ | The task is about the monthly newsletter. |

Each program folder holds overview.md, brain.md, workflow.md and data-rules.md.

## What the AI decides

- How to word a message to a volunteer.
- Which open shifts to suggest first.

## What runs the same way every time

- The schedule table keeps one row per shift.
- Dates are written the same way in every message.

## Check every answer

1. The answer sounds like voice-profile.md.
2. Nothing in the answer breaks data-rules.md.
3. Every shift and date matches the schedule.

## When something breaks

Say what broke, propose a change to the file that caused it, and wait for the team to approve it. Add a date line each time a file changes.

## When a file does not cover the question

Ask the team a question and wait for the answer.
