# How to suggest a change

You do not need to know GitHub to help. The easiest way is the feedback buttons and form on the tools page: https://dominiquecharlie.github.io/Ethical-AI-Tools/

If you do want to propose a change to the files here, you have two options.

## Option 1: Suggest an edit on GitHub (no coding)

1. Open the file you want to change in the `tools` folder.
2. Click the pencil icon ("Edit this file"). GitHub will ask you to sign in or create a free account.
3. Make your change.
4. At the bottom, write one sentence about what you changed and why, then choose "Propose changes."
5. Click "Create pull request." We review every one.

## Option 2: Open an issue

If you would rather describe the change in words, go to the Issues tab, choose "New issue," and tell us what felt off and what would help. Leave out names and confidential details about people.

## What to expect

We read every suggestion. We list the changes that came from your feedback on the tools page, so you can see what you asked for and what we did.
